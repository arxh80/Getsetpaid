# Loading-skeletons pass — decisions queue for the founder

Side pass on branch `loading-skeletons` (built on the sidebar-nav shell), not a numbered phase, so entries are labelled `LS-n` rather than continuing the phase Q-numbering. All proceeding on the stated default; each reversible.

- **LS-1 — skeletons now shimmer, reversing a recorded in-repo stance.** `components/list/list-skeleton.tsx` originally shipped **static** with a comment arguing DESIGN.md § Motion leaves no room for a shimmer and that a pulsing skeleton is on hallmark's anti-pattern list. This pass was briefed to add a shimmer, so the stance is reversed deliberately: the shimmer is a **background-colour crossfade between two existing surface tokens** (`--color-shell` ↔ `--color-pink`, 1.8s ease-in-out loop — `animate-skeleton` in `app/globals.css`), which stays inside § Motion's animatable-property list (background-color) and uses no gradient and no new colour. Under `prefers-reduced-motion` the animation is removed outright (`animation: none`, not the global 1ms clamp — 1ms × infinite is a strobe) and every skeleton returns to exactly the old static behaviour. **Default taken: shimmer ships.** Veto path: delete the `--animate-skeleton` block + the reduced-motion override in `app/globals.css` and drop `animate-skeleton` from `components/skeleton/bone.tsx` — geometry is unchanged either way.
  - The brief's phrase was "shimmer built from the existing surface tokens/--accent step". Read as the surface-token step (shell → pink, the warm neighbours). An `--accent`-blue pulse was considered and rejected: accent at bone scale is a loud fill behind nothing, the exact "fill behind a label" class DESIGN.md's two-blue rule polices. Flag if the accent-blue reading was the intended one.

- **LS-3 — record-level refusals now stream as HTTP 200; the security suite asserts the oracle property directly instead of a literal 404.** Any route-level `loading.tsx` is a Suspense boundary: on a document request Next flushes the status line (200) with the shell, so a page-level `notFound()` for a cross-tenant/out-of-scope record can only swap the body to the identical not-found document — a documented App Router streaming trade-off (Next injects `<meta name="robots" content="noindex">` into exactly this response). The first e2e run after the pass failed 14 security tests that asserted `status === 404` on such probes. **Default taken:** keep full skeleton coverage and re-express the assertions as the streaming-aware contract — never 403, never a login bounce, only 404-or-streamed-200, the identical "Page not found" document, all negative content assertions intact — plus a new load-bearing REFUSAL PARITY test (tenant-breakout.spec.ts) asserting, per entity family, that "exists, not yours" and "does not exist" return the *same* status and the *same rendered document*, and per-probe ghost-id parity in network-leakage.spec.ts. Workspace-slug refusals (thrown by the `[orgSlug]` layout above every boundary) and route handlers (document download gate) still assert the literal 404. The enumeration-oracle property is therefore *measured more directly than before*; the fixed status code was its proxy. SEO/caching posture: unchanged — streamed not-founds carry Next's injected noindex meta, and every affected route is auth-gated and fully dynamic, so no cache layer serves them at MVP. Docs reconciled in the same commit: DESIGN.md § Error pages (the HTTP-layer contract), CLAUDE.md (e2e gate row), app/(app)/not-found.tsx and the spec headers. **Veto path:** restoring literal 404s on record routes requires removing `loading.tsx` from every ancestor segment of a record URL (the hub, all nine entity lists, every detail/edit) — i.e. most of this pass — because any ancestor boundary flushes the status; say so and the pass shrinks to the ~27 leaf routes with no record 404 beneath them.

- **LS-2 — the loop duration (1.8s) sits outside the motion token scale.** DESIGN.md § Motion's durations (120/160/240ms) time one-shot state transitions; a continuous idle loop at 240ms flickers. 1.8s is the deliberate exception, same class as the sidebar's width waiver but smaller: one property, one component family, instant-off under reduced motion. Default: accept without adding a token; add a `--dur-loop` token to DESIGN.md instead if loops multiply.
