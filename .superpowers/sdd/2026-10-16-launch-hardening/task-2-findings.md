# Task 2 findings: the OWASP pass (audit phase)

Written 2026-10-17 at branch `launch-hardening`, tip `34d6afd`, read-only.
No code, test, migration or config file was changed, and no database, server
or e2e run was made: the shared local stack was in use by Task 4. Every
finding is therefore evidenced from source, from the repository's own
existing assertions, or from the installed library code. Where a finding was
not reproduced, its row says so.

**The audit stopped early on F1 (Critical),** as the brief requires. Scope
covered before the stop, and what is left, are in `task-2-report.md`.

Severity rubric (the brief's): Critical = demonstrated or plausible tenant
breakout / private-network leak / auth bypass / data loss; High = a promised
control missing or bypassable; Medium = defence-in-depth gap on a control
otherwise enforced; Low = hygiene.
